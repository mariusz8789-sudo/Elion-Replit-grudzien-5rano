# Real-Agent Street Review

The Street capture was taken after a bounded run of the existing simulation through its own 10× control. It shows real model progression: the UI reads day 3, susceptible population 253, exposed 3, infected 4 and two real transmission clusters. The visible people, changed hotspot/cluster panel and transmission rings are therefore not synthetic visual traffic.

The added instanced ground shadows improve contact between existing humanoids and the ground plane without changing any agent position, count, state, movement, contact, route or outcome. The capture reports one City3D canvas, no runtime failure, collapsed Evidence/Replay and 18.00 ms renderer time after model activity.

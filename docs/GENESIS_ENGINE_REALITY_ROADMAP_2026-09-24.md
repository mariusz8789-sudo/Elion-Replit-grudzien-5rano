## Integration order

1. Keep One Chat, one Laboratory, one Experiment Fabric, one Evidence system and one replay system.
2. Build a machine-readable capability registry for existing engines: intent, inputs, scientific label, runner, visualization, evidence adapter and replay adapter.
3. Register the already public commercial path first: candidate discovery to registered computational run to Evidence, replay and next experiment.
4. Register Chemistry, Physics and CERN live paths through the same contract.
5. Register Human macro-to-micro and microscopy paths as educational models unless a real dataset is present.
6. Register World Director, SW-4, Reality Navigator, Multiverse and spacetime scenes behind natural-language intents.
7. Connect the 5D manifold API to a state-driven world visualization and canonical run record.
8. Review the seven 9D modules individually. Reuse only modules with a useful scientific/product outcome; do not mount the package as a second product.
9. Add a single Railway scheduled job that calls OmniIngestionController every 24 hours. It may create proposals only; publication stays human-approved.
10. Replace weak hero assets after license and provenance approval. Asset quality work must not create new science engines.

## What changes when engines are connected

The user asks one question. The capability registry selects an existing runner. Experiment Fabric records the run. The matching state-driven 3D scene shows the computation. The result enters the canonical Evidence and replay path. Science Memory makes the result available to the Cognitive Core, which proposes the next bounded experiment.

Connecting an engine does not mean adding its old dashboard to navigation. Old dashboards become advanced/debug surfaces. The main product remains one Chat and one Laboratory.

## Pitch-deck boundary

### Safe to present as current capability

- One Chat routing into the main 3D laboratory and existing scientific worlds.
- Registered computational experiments with explicit scientific labels.
- Drug-discovery, chemistry, physics and CERN paths at the exact level demonstrated on public staging.
- Evidence, replay, fingerprints and persistent knowledge proposals.
- Cognitive planning, hypothesis/falsification components and Science Memory as bounded software systems.
- 5D geometry, spacetime, Multiverse and Reality as mathematical/theoretical models when their labels stay visible.

### Present only as roadmap or prototype

- Public product integration of the seven-module Genesis 9D package.
- Automatic knowledge refresh every 24 hours.
- Full premium Human Explorer and clinical-grade anatomy.
- Full walkable AI-generated laboratory environments.
- External QPU and blocked scientific workers.

### Do not claim

- AGI, consciousness or autonomous truth discovery.
- Self-learning that publishes knowledge without human review.
- A physical time machine, real wormhole travel or proof of a multiverse.
- Wet-lab execution without connected laboratory hardware.
- Clinical diagnosis or patient-specific anatomy from reference models.
- PySCF, OpenMM, Vina, PyMEEP, ADMET or toxicity execution while the public Railway health endpoint reports those runtimes blocked.

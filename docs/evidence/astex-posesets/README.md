# Astex run-4 pose sets

`astex-run4-poses.tar.gz` holds the AutoDock Vina output that run 4 generated for all 85 Astex
Diverse Set cases, and that run 5 rescored with Vinardo without re-docking. It is archived here
because these files were otherwise only in a temporary directory, and without them the run-5
result `50/85` cannot be independently reproduced.

- sha256: `b5e079cfd87b65a49d4ff55609d46833cf6230a665bd2dc80981ef8df74c7d20`
- 85 case directories, `<PDBID>/run/dock/docked.pdbqt` (20 retained poses),
  `<PDBID>/run/dock/ligand.pdbqt`, `<PDBID>/run/receptor/receptor.pdbqt` and the box definition,
  plus the crystal ligand `<PDBID>/ligand.sdf`
- the two large intermediate receptor PDB files per case are excluded; they are regenerated by the
  preparation code from the dataset

Per-case `dockedPdbqtSha256` and `receptorPdbqtSha256` are recorded in
`docs/evidence/astex-redock-run4-diagnostic.json`. `scripts/astex-vinardo-rescore.py` verifies
every one of them before scoring, so an altered archive fails the gate rather than producing a
number.

Dataset: github.com/rdk/p2rank-datasets, directory `joined/astex`, commit
`0236ecb38cbb60b89849a1ea36fbd9ee93f3e906`.

# ZEFIR Phase 4 — Speculative Physics Adversary (Tracks P/Q/R/S)

Adversarial tests of Genesis: a linguistic objection cannot overturn physics, and a
fictional device is not buildable because it can be named. NOT claims that any alleged
technology exists. No Phase-1/3 code, engine, or provenance touched. Pure module.

## `cognitive/speculativePhysics.mjs`
- **assessPhysicalClaim** — classifies a claim against a small, explicitly-heuristic
  known-physics constraint table: FTL / future-information → CONTRADICTED (relativity +
  causality); perpetual motion → CONTRADICTED (thermodynamics); forward time dilation →
  SUPPORTED; cloaking → SUPPORTED (metamaterials, partial); unknown → UNRESOLVED (honest).
- **impossibilityToInvention (R)** — decomposes a target into physical requirements →
  buildability (BUILDABLE / NOT_BUILDABLE / UNRESOLVED / MISSING_MECHANISM / …), dominant
  blocker, nearest buildable descendant, falsifiable experiment.
- **challengeModel (P)** — a challenge to established physics is admissible only with a
  FORMAL_DIVERGENCE + PARAMETER_REGION + ALTERNATIVE_PREDICTION + FALSIFIABLE_TEST; a
  linguistic objection is REJECTED. Einstein is not disproved.
- **grandfatherParadox (Q)** — separates MATHEMATICAL SOLUTION (Novikov / branching are
  consistent) vs PHYSICAL POSSIBILITY (EXPERIMENTALLY_UNSUPPORTED) vs EXPERIMENTAL
  EVIDENCE (none). The paradox refutes a specific causal model, not physics. No claim
  that time travel works.
- **lookingGlass (S4)** — future-information receiver = NOT_BUILDABLE; quantum compute =
  ACCELERATOR_ONLY (not magic); designs **Looking Glass Zero** (telemetry + state
  estimation + Monte-Carlo branching + uncertainty + forecast-failure memory) with the
  hard rule: prediction is labelled prediction, NEVER future information.

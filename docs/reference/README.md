## Non-admission rules

The reference pack does not prove that any listed source, value, license, equation, solver, dataset or benchmark has been independently verified. Claims must be checked against primary sources before entering the Genesis Scientific Knowledge Layer.

No item in these files is automatically a `FACT`, `CONNECTED`, `MODEL_AVAILABLE` or `BUILD NOW` capability. A future admitted record must preserve source URL, version, retrieval context, license/terms, units, uncertainty, assumptions, validity range, limitations and provenance.

The attached checklist is the controlling review aid for a future model–observation benchmark. In particular, a model must **predict** the observable; injecting a measured quantity as a model input is parameterization, not validation.

These files do not authorize implementation of a new solver, domain, live data provider, instrument connector, Knowledge Layer importer or second Evidence/Replay system.

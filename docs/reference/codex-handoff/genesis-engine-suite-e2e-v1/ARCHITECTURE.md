# Architecture

QUESTION
→ hypotheses
→ Experiment Planner
→ solver/tool execution
→ observation
→ Evidence Ledger
→ falsification/support
→ Meta-Cognition
→ next experiment

Other engine paths:

WORLD REQUEST
→ ModelRouter / Astra
→ World Author
→ validation
→ canonical World Director
→ canonical WorldGraph

DRUG CANDIDATE
→ identity
→ evidence/conflict/safety
→ CHEAP
→ DOCKING
→ QM
→ ADMET
→ research-priority state
→ Evidence

CYBER
→ authorized scope
→ inventory
→ risk hypotheses
→ defensive analyzers
→ finding
→ patch proposal
→ human approval
→ retest
→ Evidence

DIGITAL TWIN
→ current state
→ simulation-only intervention
→ solver
→ predicted next state
→ Evidence

The standalone hash implementation is reference/test-only. Production Genesis should inject its canonical hash.
